# Resume Screening using NLP

## 📄 Project Description
This project is a **Resume Screening System using Natural Language Processing (NLP)**.  
It helps analyze resumes and match them with job descriptions by extracting skills and calculating a match score.

This project is useful for:
- HR teams
- Recruiters
- Students learning NLP & Python

---

## 🚀 Features
- Upload resume (PDF)
- Extract skills automatically
- Compare resume with job description
- Display match percentage
- Show matched and missing skills

---

## 🛠️ Tech Stack
- Python
- Flask
- NLP (Text Processing)
- HTML (Frontend)
- VS Code
